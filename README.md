# APOL1 Risk Genotypes and Sickle Cell Trait are Associated with Kidney Disease Progression in an Afro-Brazilian Population

### 📖 Description  
This repository contains **information and instructions** for requesting the **DNA sequencing data** generated at the **Laboratório de Patologia Estrutural e Molecular (LAPEM)** from the Gonçalo Muniz Research Institute (Fiocruz-Bahia). The files of sequencing provided here are associated with the article under submission. 

---

### 📂 Contents of the files
- `electropherograms/` → Electropherogram files (.ab1)

---

### 📜 License and Use  
- Data use is restricted to **non-commercial academic research**.  
- Any usage requires citation of the associated article.

---

### 🔑 How to request the data  
The sequencing data (FASTA files and electropherograms) can be made available **upon formal request**.  

To request access:  
1. Download the **Request Form** from this repository
2. Fill out all fields in the header and sign at the end
3. Send the Request Form PDF as an attachment by e-mail to: ***washington.santos@fiocruz.br***
   - The e-mail must be sent from a valid institutional account of a professor
   - Subject: **[Data Request - LAPEM DNA sequencing files]**

The access to the data is subject to approval by the LAPEM supervisors and a link to the data set file will be sent.
